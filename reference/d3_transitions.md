# Configure D3 transitions for the widget

Configure D3 transitions for the widget

## Usage

``` r
d3_transitions(widget, duration = 500, easing = "cubic-in-out")
```

## Arguments

- widget:

  A gg2d3 widget.

- duration:

  Transition duration in milliseconds (default: 500). Set to 0 to
  disable.

- easing:

  Easing function name (default: "cubic-in-out").

## Value

The modified widget.
