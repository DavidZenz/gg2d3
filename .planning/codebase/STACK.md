# Technology Stack

**Analysis Date:** 2026-03-11

## Languages

**Primary:**
- R - Core package language for gg2d3 R package
- JavaScript (ES6) - D3 rendering engine and UI logic

## Runtime

**Environment:**
- R (version unspecified in DESCRIPTION, but RoxygenNote: 7.3.3 indicates modern R)
- Node.js - For development/build tooling (vendored D3.js)
- Web browser - For D3 rendering via htmlwidgets

**Package Manager:**
- R: devtools, roxygen2 (for documentation generation)
- JavaScript: Vendored D3.js (no npm package.json)

## Frameworks

**Core:**
- ggplot2 - Provides ggplot objects that gg2d3 converts to IR
- htmlwidgets - R framework for creating interactive HTML/JavaScript widgets
- D3.js v7 - JavaScript visualization library for SVG rendering

**Testing:**
- testthat (>= 3.0.0) - R unit testing framework
- Config: R/testthat/edition 3

**Build/Dev:**
- roxygen2 - Documentation generation from R comments
- devtools - Development workflow utilities

## Key Dependencies

**Critical:**
- ggplot2 - Core dependency; gg2d3 converts ggplot2 objects via `ggplot_build()`
- htmlwidgets - Provides `createWidget()` for wrapping D3 as R widget
- D3.js v7 - Renders IR as SVG visualization in browser
  - Vendored locally: `inst/htmlwidgets/lib/d3/d3.v7.min.js`
  - No npm dependency; must be downloaded manually (see CLAUDE.md)

**Optional/Suggested:**
- crosstalk - Enables linked brushing across gg2d3 and other Crosstalk-compatible widgets (Shiny, DT, plotly, leaflet)
  - Used in `R/gg2d3.R` via `crosstalk::is.SharedData()` and `crosstalk::crosstalkLibs()`
  - JavaScript integration in `inst/htmlwidgets/modules/crosstalk.js`

## Configuration

**Environment:**
- `.Rproj` file: `gg2d3.Rproj` - RStudio project configuration
  - Settings: UseSpacesForTab=Yes (2 spaces), Roxygen enabled, devtools build

**Build:**
- `DESCRIPTION` - Package metadata (title, version, authors, dependencies)
- `NAMESPACE` - Generated by roxygen2 from `R/` files with `@export` tags
- `.Rbuildignore` - Excludes files from R package build (README.Rmd, docs, node_modules, etc.)

**htmlwidgets Configuration:**
- `inst/htmlwidgets/gg2d3.yaml` - Widget registration and dependency declaration
  - Declares D3 v7 dependency
  - Lists module JS files (geoms, scales, theme, etc.) in load order
  - Script entry point: `gg2d3.js`

## Platform Requirements

**Development:**
- R environment with devtools, roxygen2
- Internet connection to download D3.js (one-time setup)
- RStudio (optional but standard)

**Runtime/Production:**
- Modern web browser with ES6 JavaScript support
- D3.js v7 (vendored, no external CDN required)

## JavaScript Module Architecture

**Main Widget:**
- `inst/htmlwidgets/gg2d3.js` - HTMLWidgets factory, main rendering orchestration (~1000 lines)

**Core Modules:**
- `inst/htmlwidgets/modules/constants.js` - Unit conversion (mm→px, W3C standard DPI)
- `inst/htmlwidgets/modules/scales.js` - D3 scale creation (continuous/categorical)
- `inst/htmlwidgets/modules/theme.js` - Theme element rendering (grids, axes, backgrounds)
- `inst/htmlwidgets/modules/layout.js` - Panel layout and positioning
- `inst/htmlwidgets/modules/events.js` - Mouse/interaction event handlers

**Interactive Features:**
- `inst/htmlwidgets/modules/zoom.js` - D3 zoom behavior
- `inst/htmlwidgets/modules/brush.js` - D3 brush selection
- `inst/htmlwidgets/modules/crosstalk.js` - Linked brushing via Crosstalk library
- `inst/htmlwidgets/modules/tooltip.js` - Hover tooltips
- `inst/htmlwidgets/modules/legend.js` - Legend rendering

**Geom Renderers:**
- `inst/htmlwidgets/modules/geoms/point.js` - Circle rendering (circles from numeric mm diameter)
- `inst/htmlwidgets/modules/geoms/line.js` - Line/path rendering
- `inst/htmlwidgets/modules/geoms/bar.js` - Bar/column chart rendering
- `inst/htmlwidgets/modules/geoms/rect.js` - Rectangle/tile rendering
- `inst/htmlwidgets/modules/geoms/text.js` - Text labels
- `inst/htmlwidgets/modules/geoms/area.js` - Filled areas
- `inst/htmlwidgets/modules/geoms/ribbon.js` - Ribbon (two-series area)
- `inst/htmlwidgets/modules/geoms/segment.js` - Line segments (used by geom_hline, vline, abline)
- `inst/htmlwidgets/modules/geoms/boxplot.js` - Box-and-whisker plots
- `inst/htmlwidgets/modules/geoms/violin.js` - Violin plots
- `inst/htmlwidgets/modules/geoms/density.js` - Density curves
- `inst/htmlwidgets/modules/geoms/smooth.js` - Smooth regression curves
- `inst/htmlwidgets/modules/geoms/reference.js` - Reference geoms (no rendering, helper)

**Utilities:**
- `inst/htmlwidgets/modules/geom-registry.js` - Geom dispatch and rendering coordination

## R Code Organization

**Entry Points:**
- `R/gg2d3.R` - Main widget function `gg2d3()` for R users
  - Accepts ggplot objects or IR lists
  - Handles optional Crosstalk SharedData detection
  - Returns htmlwidgets widget

**IR Generation:**
- `R/as_d3_ir.R` - ggplot2 → IR converter (~450 lines)
  - Extracts ggplot2 structure via `ggplot_build()`
  - Converts scales, layers, theme to JSON-serializable IR
  - Handles discrete/continuous value mapping

**Interactive Features (exported):**
- `R/d3_tooltip.R` - Tooltip configuration
- `R/d3_hover.R` - Hover highlight configuration
- `R/d3_zoom.R` - Zoom configuration
- `R/d3_brush.R` - Brush selection configuration
- `R/d3_crosstalk.R` - Crosstalk integration utilities

**Validation:**
- `R/validate_ir.R` - IR validation and diagnostics
