g.append("path")
  .datum(publicRow)
  .attr("class", "geom-polygon")
  .attr("d", closedLine(pts));
publicRow._polygonPoints = pts;

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IR rows -> SVG attributes | User plot data is converted to SVG `d`, fill, stroke, stroke-width, opacity, and dash attributes. |
| Renderer-private points -> public callbacks | `_polygonPoints` is needed for path updates but must remain private and sanitizer-compatible. |
| htmlwidgets yaml -> browser runtime | Local module loading order controls whether the registered renderer exists before dispatch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-04 | Tampering | `polygon.js` SVG attributes | mitigate | Coerce x/y to finite/scaled values, skip invalid groups, use existing color/linetype helpers, and explicitly convert missing fill/stroke to `none` rather than arbitrary strings. |
| T-44-05 | Information Disclosure | `publicRow._polygonPoints` | mitigate | Keep renderer-private point data underscore-prefixed and verify Plan 44-03 sanitizers drop underscore fields from callbacks. |
| T-44-06 | Denial of Service | closed path rendering | accept | Small representative fixtures are tested; large-dataset performance is outside v1.11 Phase 44 requirements. |
| T-44-07 | Elevation of Privilege | yaml/module loading | mitigate | Add only local `geoms/polygon.js`; do not add remote scripts, new dependencies, or executable callback APIs. |
</threat_model>
