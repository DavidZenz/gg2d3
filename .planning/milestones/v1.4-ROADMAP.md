# Roadmap: gg2d3

## Overview

This roadmap defines milestone **v1.4 Comprehensive Theme Parity & Reference Geoms**. The phase structure continues from v1.3 and focuses on deep visual fidelity and common annotation helpers.

## Milestones

- ✅ **v1.0 MVP** — Phases 1-12 (shipped 2026-02-16)
- ✅ **v1.1 Interactive Exploration** — Phases 13-15 (shipped 2026-03-31)
- ✅ **v1.2 Smooth Transitions & Scale Parity** — Phases 16-17 (shipped 2026-03-31)
- ✅ **v1.3 Advanced Facets & Custom Interactivity** — Phases 18-19 (shipped 2026-03-31)
- 🟡 **v1.4 Comprehensive Theme Parity & Reference Geoms** — Phases 20-21 (planned)

## Phases

### Phase 20 - Deep Theme Inheritance

**Goal:** Implement full `theme()` inheritance logic and support for detailed element styling.

**Requirements:** THEME-01, THEME-02, THEME-03

**Success Criteria (observable):**
1. User can use `element_blank()` to hide any theme element.
2. Legend box styling (fill, colour) reflects theme settings.
3. Text justifications and margins are correctly applied to all labels.

### Phase 21 - Reference Geoms

**Goal:** Provide `geom_hline`, `geom_vline`, and `geom_abline` for annotations.

**Requirements:** GEOM-16, GEOM-17

**Success Criteria (observable):**
1. Horizontal and vertical lines are correctly positioned on continuous/discrete scales.
2. `geom_abline` renders correctly within the panel clipping area.
