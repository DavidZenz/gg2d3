# Roadmap: gg2d3

## Overview

This roadmap defines milestone **v1.2 Smooth Transitions & Scale Parity**. The phase structure continues from v1.1 and focuses on adding fluid animations and deepening scale parity with ggplot2.

## Milestones

- ✅ **v1.0 MVP** — Phases 1-12 (shipped 2026-02-16)
- ✅ **v1.1 Interactive Exploration** — Phases 13-15 (shipped 2026-03-31)
- 🟡 **v1.2 Smooth Transitions & Scale Parity** — Phases 16-17 (planned)

## Phases

### Phase 16 - Animated Transitions

**Goal:** Users see smooth, object-constant animations during interactive changes (zoom, brush, crosstalk).

**Requirements:** TRAN-01, TRAN-02, TRAN-03, TRAN-04

**Success Criteria (observable):**
1. Marks transition smoothly (not jump) when axes zoom or filter.
2. Axes transition their ticks and labels on a synchronized timeline with marks.
3. User can disable animations via R (`d3_transitions(none)`) or system preference.

### Phase 17 - Advanced Scale Parity

**Goal:** Users can configure advanced scale behaviors (`breaks`, `minor_breaks`, `expand`, `oob`) and see them reflected in D3.

**Requirements:** SCALE-01, SCALE-02, SCALE-03

**Success Criteria (observable):**
1. Custom `breaks` and `minor_breaks` are honored for all scale types.
2. `oob` (out of bounds) logic (squish, censor) matches ggplot2.
3. `expand` multiplicative and additive expansion is correctly applied to domains.
