# Requirements: gg2d3

**Defined:** 2026-03-31
**Milestone:** v1.4 Comprehensive Theme Parity & Reference Geoms
**Core Value:** Any ggplot2 plot should render identically in D3 - same visual output, but now interactive and web-native.

## v1 Requirements

Requirements committed for milestone v1.4.

### Theme Parity

- [ ] **THEME-01**: User sees theme inheritance correctly applied (blank elements, recursive lookup from parent elements).
- [ ] **THEME-02**: User sees text elements respect complex theme properties (vjust, hjust, margin, lineheight).
- [ ] **THEME-03**: User sees legend box styling (background, border, title alignment) match theme configuration.

### Reference Geoms

- [ ] **GEOM-16**: User can render `geom_hline` and `geom_vline` with correct intercept placement and mapping.
- [ ] **GEOM-17**: User can render `geom_abline` with correct slope/intercept handling across continuous/discrete scales.
