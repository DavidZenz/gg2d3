<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer private state -> public callback payloads | `_geom` and `_centroid` must not leave renderer internals through tooltip, handler, or brush APIs. |
| Chrome runtime -> test result | Console/page errors must be captured and considered in pass/fail state. |
| brush DOM gesture -> selected data callback | Browser brush selection converts DOM anchors into public selected data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-01 | Information Disclosure | `events.js`, `tooltip.js`, `brush.js` runtime payloads | mitigate | Browser tests click, hover, and brush live `path.geom-sf` nodes and assert `_geom` and `_centroid` are absent from public payloads. |
| T-36-03 | Repudiation | chromote runtime errors | mitigate | Capture `Runtime.consoleAPICalled` and `Runtime.exceptionThrown`, persist logs, and fail tests on errors/assertions. |
| T-36-05 | Tampering | interaction fixture behavior | mitigate | Build the interactivity fixture from deterministic choropleth input and assert zoom suppression plus expected globals before accepting callback results. |
</threat_model>
