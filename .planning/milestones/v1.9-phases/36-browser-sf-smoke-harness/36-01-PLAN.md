| local fixture file -> Chrome runtime | Generated htmlwidgets files execute JavaScript in headless Chrome. |
| renderer datum -> callback payload | Private renderer fields cross into user-facing tooltip, handler, or brush payloads if sanitization fails. |
| test harness -> filesystem artifacts | Browser logs and HTML artifacts are written to ignored local output paths. |
