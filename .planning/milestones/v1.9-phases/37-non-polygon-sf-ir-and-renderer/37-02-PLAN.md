<objective>
Update the D3 sf renderer so the Phase 37 IR renders polygon, point, and line sf families through one panel projection, shared `.geom-sf` selector semantics, family-specific classes, stable row ids, finite anchors, and core visible styling.
</objective>

<threat_model>
## Threat Model

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Renderer-private fields leak into public rows | medium | Keep `_geom`, `_centroid`, `_sfFamily`, and any child coordinate fields internal; Plan 37-03 verifies sanitization. |
| Point and line renderer adds unsafe external runtime code | high | Modify only local `sf.js`; do not add remote scripts, Node tooling, or runtime browser dependencies. |
| Non-polygon marks bypass existing selector-based interactivity | medium | Every new mark gets shared `geom-sf` plus family-specific class and row/anchor attributes. |
</threat_model>
