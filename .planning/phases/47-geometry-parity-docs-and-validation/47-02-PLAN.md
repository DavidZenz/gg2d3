## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Roxygen source -> generated help | `R/*.R` roxygen comments generate tracked `man/*.Rd` artifacts. |
| README source -> generated README | `README.Rmd` generates tracked `README.md`. |
| Renderer/test internals -> help pages | Private renderer fields and test implementation details can accidentally become documented public API. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47-01 | Information Disclosure | public help docs | mitigate | Keep support wording tied to sanitized public payload tests; do not document `_geom`, `_centroid`, `_sfFamily`, or `_sfAnchor` as public payload fields. |
| T-47-02 | Tampering / Integrity | generated README/help | mitigate | Edit source docs first, regenerate with `devtools::document(); devtools::build_readme()`, and inspect generated diffs instead of primary manual generated-file edits. |
| T-47-03 | Repudiation | stale generated artifacts | mitigate | Run RTK-prefixed inverted Rscript stale-claim checks across source and generated docs after regeneration. |
</threat_model>
