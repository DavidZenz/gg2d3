Existing public `geom_sf()` contract:
- Accepted geometry families: `POLYGON`, `MULTIPOLYGON`, `POINT`, `MULTIPOINT`, `LINESTRING`, `MULTILINESTRING`.
- Unsupported, empty, invalid, or missing rows are skipped with warnings while accepted rows remain renderable.
- Known CRS inputs are normalized in R; missing CRS coordinates are serialized as-is with a warning.
- Tooltip, hover, handlers, and brush use `.geom-sf` marks and sanitized source-row payloads.
- Brush uses representative anchors from `data-cx`/`data-cy`, not true geometry-overlap brushing.
- `d3_zoom()` suppresses widgets containing `geom_sf()` layers with the existing warning.
- Map anti-features remain explicit: no tile basemaps, slippy map controls, JavaScript-side CRS reprojection, true geometry-overlap brushing, `GEOMETRYCOLLECTION` expansion, or large-map performance guarantees.

Locked constraints:
- Do not modify package behavior.
- Do not implement ordinary `geom_polygon()` or rect/tile renderer work.
- Do not add Playwright, Puppeteer, Selenium, screenshot diff, or visual diff requirements.
