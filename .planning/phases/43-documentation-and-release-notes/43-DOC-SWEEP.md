## Verification Summary

- Source docs were updated before generated files.
- Generated docs were refreshed with `rtk Rscript --vanilla -e 'devtools::document(); devtools::build_readme()'`.
- Positive source/generated scans found the shipped polygon-family,
  point-family, and line-family `geom_sf()` contract, optional browser
  validation, map anti-features, representative-anchor brushing, sanitized
  source-row payloads, and zoom suppression language.
- Negative scans found no stale v1.9 support-contract wording, polygon-only
  `geom_sf()` support wording, or browser tooling requirements.

- No JavaScript renderer files were modified.
- No ordinary `geom_polygon()` renderer was added; ordinary `geom_polygon()`
  remains a deferred non-blocker separate from supported `geom_sf()`
  polygon-family rendering.
- No rect/tile renderer behavior was changed; rect/tile out-of-bounds behavior
  remains deferred non-blocking renderer debt.
- No browser tooling stack was added or required.
