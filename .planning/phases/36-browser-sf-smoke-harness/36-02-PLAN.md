<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated HTML -> chromote browser | Saved widgets are opened by headless Chrome through local file paths. |
| fixture matrix -> browser test expectations | A stale or wrong fixture file could satisfy broad DOM checks unless exact names and counts are asserted. |
| browser DOM -> testthat assertions | Live DOM values are untrusted until queried and validated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-02 | Tampering | `test-sf-browser.R` fixture navigation | mitigate | Assert exact six fixture filenames, deterministic `test_output` paths, and expected path counts before accepting a loaded widget. |
| T-36-03 | Repudiation | DOM smoke test result | mitigate | Use browser helper error collection from Plan 01 and keep failure artifacts when DOM assertions fail. |
| T-36-04 | Denial of Service | render polling | accept | Bounded `wait_for_sf_paths(..., timeout = 10)` limits local browser wait time; tests skip when browser prerequisites are unavailable. |
</threat_model>
