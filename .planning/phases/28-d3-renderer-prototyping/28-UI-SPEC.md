## Color

### SVG Path Elements (geom_sf output)

The sf renderer must pass fill/stroke through from the IR aesthetic data. The contracts below describe the SVG attribute values the renderer writes.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#4393c3` (ggplot2 default geom_sf fill) | Default fill for `<path>` elements when no fill aesthetic is mapped |
| Secondary (30%) | `#ffffff` (ggplot2 default panel background) | SVG background rect behind the map panel |
| Accent (10%) | `#222222` | Polygon border stroke — `<path stroke>` attribute on all sf paths |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for: polygon border strokes on `<path>` elements in sf layers only.

### Fill/Stroke Passthrough Rule

When the IR carries a `fill` or `colour` aesthetic column, the renderer reads the per-row value via `makeColorAccessors()` and applies it directly to the SVG `fill` and `stroke` attributes. The default values above apply only when IR aesthetic columns are absent or NA.

Source: CONTEXT.md D-07, RESEARCH.md REND-03, geom-registry.js `makeColorAccessors()` pattern.

### Fill Rule

Apply `fill-rule="evenodd"` to every `<path>` element unconditionally.

Source: CONTEXT.md D-08.

### Visual Test HTML Color

| Role | Value | Usage |
|------|-------|-------|
| Page background | `#f5f5f5` | `<body>` background in test HTML |
| Panel border | `#cccccc` 1px solid | Border around each comparison panel in test files |
| Label text | `#333333` | Caption text below each panel |

Source: default — matches existing `test_output/` file conventions.

## SVG Attribute Contract

These are the concrete SVG attributes `sf.js` must write to each `<path>` element.

| Attribute | Value | Source |
|-----------|-------|--------|
| `d` | GeoJSON path string from `d3.geoPath()(feature.geometry)` | D3 geoPath computation |
| `fill` | per-row fill color from `makeColorAccessors()`, or `#4393c3` if absent | CONTEXT D-07, RESEARCH REND-03 |
| `stroke` | per-row colour from `makeColorAccessors()`, or `#222222` if absent | CONTEXT D-07 |
| `stroke-width` | `0.5` (px) | default — thin border matching ggplot2 geom_sf default |
| `fill-rule` | `evenodd` | CONTEXT D-08 |
| `opacity` | per-row opacity from `makeColorAccessors()`, or `1` | CONTEXT D-07 |
| `data-cx` | computed centroid x (px) from `d3.geoPath().centroid()` | CONTEXT D-11 |
| `data-cy` | computed centroid y (px) from `d3.geoPath().centroid()` | CONTEXT D-11 |
| `class` | `geom-sf` | discretionary — follows existing `geom-{name}` CSS class pattern |
| `data-row-id` | `row_id` value from geometry record | CONTEXT D-06, join key for Phase 29 brush selection |

## Interaction Contract

Phase 28 is a rendering prototype — no interactive behaviors are implemented. The following are prep-only contracts for downstream phases.

| Element | Phase 28 Prep | Downstream Consumer |
|---------|---------------|---------------------|
| `data-cx` / `data-cy` on `<path>` | Must be written with centroid coordinates | Phase 29 brush selection (INTR-02) |
| `data-row-id` on `<path>` | Must match `row_id` in `layer.data[]` | Phase 29 hover/tooltip (INTR-01) |
| `class="geom-sf"` on `<path>` | Selector for future CSS/event attachment | Phase 29 interactivity modules |

No click handlers, hover listeners, or tooltip triggers are attached in this phase.
