## Trust Boundaries

| User sf data -> ggplot2 built data | User-controlled sf geometries and labels enter ggplot2 layer build output. |
| ggplot2 built data -> gg2d3 IR | Built sf annotation rows become JSON-serializable rows and GeoJSON geometry strings. |
| IR validation -> D3 renderer | New geom names must be structurally validated before browser rendering. |
