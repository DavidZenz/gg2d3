<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SVG annotation mark -> event callbacks | Bound annotation data crosses into user-provided tooltip, hover, and handler callbacks. |
| SVG annotation mark -> brush callback payload | Selected annotation rows are collected from DOM elements and returned to brush callbacks. |
| Local widget HTML -> chromote browser | Optional tests execute local htmlwidgets JavaScript in a browser session. |
| Test evidence -> verification notes | Automated command results become phase-level evidence for future planning and docs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-10 | Information Disclosure | tooltip/handler/brush payloads | mitigate | Source and browser tests assert underscore-prefixed renderer fields are stripped from public payloads. |
| T-46-11 | Tampering | selector plumbing | mitigate | Tests assert annotation marks carry `.geom-sf` and use existing selector arrays rather than new APIs. |
| T-46-12 | Spoofing | brush selected rows | mitigate | Browser smoke selects around `data-cx` / `data-cy` anchors and expects stable public `row_id` / `label` rows. |
| T-46-13 | Elevation of Privilege | browser smoke tooling | mitigate | Reuse optional chromote/testthat helpers only; do not add remote browser stacks or screenshot tools. |
| T-46-14 | Repudiation | verification evidence | mitigate | Record exact commands, pass/skip status, requirement coverage, and residual risks in `46-VERIFICATION.md`. |
</threat_model>
