<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sf annotation IR -> renderer rows | Geometry strings and public data rows become renderer-bound SVG mark data. |
| Projected anchor -> SVG attributes | Computed projected anchors become `x`, `y`, `data-cx`, and `data-cy`. |
| Label text -> SVG text nodes | User-provided labels become text node content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-05 | Tampering | `gg2d3.js` filtering | mitigate | Source tests require sf-like data/geometries pair filtering for `sf_text` and `sf_label`. |
| T-46-06 | Denial of Service | projected anchors | mitigate | Renderer filters non-finite anchors and empty labels before appending SVG marks. |
| T-46-07 | Information Disclosure | renderer-bound rows | mitigate | Private geometry/anchor fields are underscore-prefixed for existing sanitizer paths. |
| T-46-08 | Spoofing | label DOM structure | mitigate | Stable class names distinguish text marks, label groups, label boxes, and label text. |
| T-46-09 | Cross-site scripting | label text | mitigate | Use D3 `.text(...)` for label content, not `.html(...)`, so labels become text nodes. |
</threat_model>
