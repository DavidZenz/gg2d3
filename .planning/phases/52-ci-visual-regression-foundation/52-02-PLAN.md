<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> R package tests | Hosted runner environment supplies R, package dependencies, and Chrome/Chromium. |
| Test output -> uploaded artifact | Ignored local files are uploaded for CI inspection without being committed. |
| PR trigger -> repository workflow | Pull requests execute the smoke workflow with read-only permissions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-04 | D | Browser discovery in CI | mitigate | Fail the workflow if no Chrome/Chromium executable is found; do not let this become an allowed CI skip. |
| T-52-05 | I | Artifact upload | mitigate | Upload only `test_output/browser-visual-smoke/`, which contains generated diagnostics; keep source artifacts ignored and out of commits. |
| T-52-06 | E/T | Workflow permissions | mitigate | Use `permissions: read-all` and avoid publishing/deploying steps in the visual-smoke workflow. |
</threat_model>
