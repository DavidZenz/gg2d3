<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local test mode -> CI test mode | Environment variables decide whether browser unavailability skips or fails. |
| Browser artifacts -> CI report | Generated rows and files become diagnostic evidence for maintainers. |
| Optional dependency status -> CI result | Spatial package availability can create skipped rows without masking browser failures. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-01 | R/D | `skip_browser_visual_smoke()` | mitigate | Use `GG2D3_BROWSER_VISUAL_CI=true` as explicit CI mode; browser-level missing dependencies fail only in this mode. |
| T-52-02 | T/I | `write_browser_visual_index()` and `validate_browser_visual_rows()` | mitigate | Validate row status, artifact links, skip/failure reasons, and metadata before writing the report. |
| T-52-03 | I | Browser metadata | accept | Store only run metadata, env flags, browser path/version, and artifact links; do not embed browser log contents in public docs. |
</threat_model>
