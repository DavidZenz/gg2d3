# Phase 42 - Validation Strategy

> Per-phase validation contract for release-gate planning and execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | testthat edition 3, devtools, roxygen2, R CMD build/check |
| **Config file** | `DESCRIPTION`, `tests/testthat.R`, `.Rbuildignore`, `.gitignore` |
| **Quick run command** | `rtk Rscript --vanilla -e 'devtools::load_all(quiet = TRUE); testthat::test_file("tests/testthat/test-regression-core.R"); testthat::test_file("tests/testthat/test-sf-browser.R")'` |
| **Full suite command** | `rtk Rscript --vanilla -e 'devtools::document(); devtools::build_readme(); devtools::test()'` plus `rtk R CMD build` and `rtk R CMD check --as-cran` from a scratch directory |
| **Estimated runtime** | Quick tier: under 2 minutes when browser/spatial checks skip; full tier: depends on local R package check runtime |

---

## Sampling Rate

- **After every task commit:** Run the narrow source/file checks named in the task's `<verify>` block.
- **After every plan wave:** Run the quick release-surface gate or the strongest lower-cost subset available for that wave.
- **Before `$gsd-verify-work`:** Run the full release gate where local tooling permits and record expected optional skips.
- **Max feedback latency:** Keep task-level feedback under 2 minutes; full `R CMD check` is allowed to exceed that because it is the release gate itself.
