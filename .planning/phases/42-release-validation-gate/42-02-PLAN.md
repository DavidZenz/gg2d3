<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maintainer shell -> R package tooling | Release commands run local R code, docs generation, tests, build, and check. |
| R CMD check -> scratch filesystem | Package build/check writes tarball and `*.Rcheck` artifacts under `/private/tmp`. |
| Browser smoke -> ignored artifacts | Optional chromote smoke tests may write HTML/log/JSON under `test_output/browser-sf/`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-02-01 | Tampering | Full gate shell commands | mitigate | Use fixed commands from `42-VALIDATION-GATE.md`; derive package version from `DESCRIPTION`; do not execute arbitrary paths from user input. |
| T-42-02-02 | Information Disclosure | Source package tarball | mitigate | Keep `.Rbuildignore` exclusions from Phase 40; record check artifacts under `/private/tmp` rather than adding them to source. |
| T-42-02-03 | Denial of Service | `R CMD check --as-cran` | accept | Full release gate can be long-running; this is required release validation, with quick gate retained for shorter feedback. |
| T-42-02-04 | Elevation of Privilege | Optional dependency installation | mitigate | Do not install optional `sf`, Chrome, or browser tooling in this plan without explicit maintainer approval. |
</threat_model>
