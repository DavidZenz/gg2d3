## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maintainer shell -> testthat | Environment variables decide whether browser artifacts are generated. |
| Fixture matrix -> local browser | Fixture widgets are rendered by Chrome through chromote. |
| Optional spatial packages -> row status | sf-dependent rows can execute or skip independently of non-sf rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01 | I | Visual smoke generated artifacts | mitigate | Generate only under `test_output/browser-visual-smoke/`; assert index and per-row files live there; do not add generated outputs to git. |
| T-48-02 | T/E | Fixture IDs and DOM evidence scripts | mitigate | Use sanitized fixed fixture IDs; route all DOM summary work through helper-owned static JavaScript; do not accept arbitrary fixture-supplied JS. |
| T-48-03 | T/D | Browser runner dependency stack | mitigate | Reuse existing R/testthat/chromote/htmlwidgets stack only; no Playwright, Puppeteer, Selenium, webshot2, pixel diffs, or committed goldens. |
</threat_model>
