## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sf input data -> IR | Untrusted geometry rows are filtered into accepted and skipped row sets. |
| IR -> D3 renderer | Accepted data/geometries become SVG paths and interactive marks. |
| renderer internals -> callbacks | Internal `_geom` and `_centroid` fields must not leak to user handlers, tooltips, Shiny, or brush callbacks. |

| T-35-04 | Information Disclosure | event/tooltip/brush callback payloads | mitigate | Assert underscore-prefixed renderer-private fields are sanitized by event, tooltip, and brush modules before user-facing callbacks. |

</threat_model>
