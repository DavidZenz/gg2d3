  - Why this works at the rendering layer: browsers composite transformed SVG groups via the same GPU path as CSS transforms; cost is independent of feature count.
  - Embed the expected DOM example from RESEARCH.md verbatim.

  H3: `### D-09: vector-effect non-scaling-stroke mitigation`
  - Spec verbatim: each `<path class="geom-sf">` carries `vector-effect="non-scaling-stroke"` as an **SVG presentation attribute** (NOT a CSS rule).
  - Rationale: presentation attributes survive `htmlwidgets::saveWidget(selfcontained=TRUE)` serialization and the pkgdown vignette pipeline (DOCS-02 context). A CSS class would not.
  - Browser support note: all evergreen browsers since 2014 (MDN citation: https://developer.mozilla.org/en-US/docs/Web/SVG/Attribute/vector-effect).
  - Pitfall warning (cite RESEARCH.md Pitfall 3): do NOT spec this as `.geom-sf { vector-effect: ... }` CSS.

  H3: `### D-10: Divergence from existing zoom.js element-repositioning pattern`
  - State the divergence: every non-sf geom uses element-repositioning (`zoom.js` lines 365-494 — `repositionElements()` iterates per-geom and resets cx/cy or x/y/width/height). sf uses SVG group transform.
  - Three reasons the existing pattern cannot be reused (cite RESEARCH.md "Zoom Architecture Divergence Rationale"):
    1. **No equivalent of `xScale(d.x)`** — sf geometry is GeoJSON projected through `d3.geoIdentity().reflectY(true).fitExtent()`. Repositioning under zoom requires rebuilding the projection with the zoomed bbox and re-running `pathGen()` per feature. Hundreds of ms per wheel tick for thousands of vertices.
    2. **geoPath's fitExtent is bbox-driven, not transform-driven** — no `geoPath.rescale(zoomTransform)` analog exists.
    3. **SVG group transform is GPU-composited** — cost is independent of feature count.
  - Build-phase target: `zoom.js` `zoomed()` handler. The divergence is documented here so the build phase does NOT try to retrofit sf into `repositionElements()`.

  H3: `### D-11: Zoom event integration`
  - Spec the new branch in `zoom.js` `zoomed()` handler (near line 126). Embed the exact JS from RESEARCH.md "Code Examples" "Zoom handler branch":

    var sfLayer = panelGroup.select('.sf-zoom-layer');
