<interfaces>
Key source contracts for this docs-only phase:

From `29-CONTEXT.md`:
- D-01: `d3_tooltip()` for `geom_sf` should prioritize original ggplot mapped variables through `ir.aes_by_var`.
- D-02: `d3_hover()` should reuse existing hover behavior by adding `path.geom-sf` to selector lists.
- D-03: Tooltip content comes from the bound row object on each path; `data-row-id` is not the primary tooltip source.
- D-04: Do not duplicate tooltip values into DOM `data-*` attributes.
- D-05: `d3_brush()` selects sf regions by stored centroid inside the brush rectangle.
- D-06: Document centroid-based region selection, not polygon-overlap selection.
- D-07: Brush callbacks return bound row objects, not GeoJSON payloads.
- D-08: `brush.js` should prefer `data-cx` and `data-cy` for `path.geom-sf`.
- D-09: First build suppresses `d3_zoom()` for widgets containing sf panels.
- D-10: `d3_zoom()` suppression should be visible from R as a warning.
- D-11: Map zoom is deferred; future candidate is projection/path re-rendering.
- D-12: SVG group transform is rejected because it scales stroke widths.

From `29-PATTERNS.md`:
- The design document title must be `Phase 29 - Interactivity Design Contract`.
- The document must name `path.geom-sf`, `data-row-id`, `data-cx`, `data-cy`, `d3_tooltip()`, `d3_hover()`, `d3_brush()`, and `d3_zoom()`.
- The document must include a comparison table with `Centroid inside brush`, `Polygon overlap / hit-testing`, and `Disable brush`.
- Package source files are future implementation hooks and must not be edited in this phase.
