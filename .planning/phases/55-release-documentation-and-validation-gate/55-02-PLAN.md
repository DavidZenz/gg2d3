<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command output -> gate evidence | Raw local logs must be summarized accurately without being published wholesale. |
| optional dependency skip -> release confidence | Browser/spatial skips can hide real failures if not classified. |
| source tree -> package check | Package check artifacts must not pollute the repo or rely on repo-only paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-04 | Repudiation | `55-GATE-RUN.md` | mitigate | Record exact commands, working directories, outcomes, skip classes, and blocker status for every gate command. |
| T-55-05 | Information Disclosure | Browser/check artifacts | mitigate | Store only path summaries and counts; forbid raw browser logs, screenshots, HTML, JSON dumps, and `00check.log` excerpts in committed files. |
| T-55-06 | Spoofing / Tampering | Browser visual CI evidence | mitigate | Prefer `gh` workflow run/artifact metadata when authenticated; otherwise explicitly record fallback artifact path and auth limitation rather than claiming fresh CI evidence. |
| T-55-07 | Denial of Service / Reliability | Package check | mitigate | Run build/check from `/private/tmp`; ERROR/WARNING blocks release readiness, NOTEs require explicit classification. |
</threat_model>
